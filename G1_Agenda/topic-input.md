# Themen-Input

Zu Beginn des Unterrichts fassen 2-3 Lehrlinge als Teamarbeit die wichtigsten Erkenntnisse aus Ihrer
Recherche zu dem aufgeführten Themen als Kurzpräsentation (max. 20 min) zusammen.

Die Präsentation wird im Anschluss der Klasse im OneNote (Platz für Zusammenarbeit) zur Verfügung gestellt.
**Die Präsentation wird nicht benotet.**

</br>

## Wichtig

- **Kein PowerPoint. Die Präsentation hat im Markdown Format zu erfolgen.**

- OR-Mapper Frameworks
  - Produkteübersicht

  - Voraussetzungen
  - Vor-/Nachteile
  - Code Beispiele
- Entity Framework

  - DbSet<> Klasse
